# JY Global Trade LLC 🌎

### International Trade | Import & Export | Brokerage | Logistics

**JY Global Trade LLC** is a bilingual business website developed to present international trade services and connect businesses with commercial opportunities.

## 🚀 Live Website

https://jyglobaltradeusa.com

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git and GitHub

## ✨ Features

- Bilingual website (English and Spanish)
- Responsive layout for desktop, tablet, and mobile devices
- Business services and industry sectors pages
- Contact form integration using Formspree
- Search engine optimization (SEO) elements

## 📁 Project Structure

- `css/` — Stylesheets
- `img/` — Images and visual assets
- `js/` — JavaScript files
- `en/` — English-language pages
- Root HTML files — Spanish-language pages

## 👩‍💻 My Role

Designed, developed, and deployed the website, including page layouts, responsive styling, bilingual content integration, contact form configuration, and hosting setup.

## 📌 Project Status

Live website — ongoing maintenance and improvements.
